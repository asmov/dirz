DESIGN: DirZ Tote
================================================================================
DirZ Tote is designed to maintain an entire **organizational** filesystem.

Filesystem **encryption** is configurable and can be performed by either [gocryptfs](https://nuetzlich.net/gocryptfs) or [CryFS](https://www.cryfs.org).

File **journaling** is performed by Git, even for office documents.

Tools are provided to simplify office **user workflow** as much as possible.

Entire filesystems can be maintained on an upstream server and used from downstream workstations.

DirZ Tote can be easily backed up on **removable disks** (downstream) and **cloud storage** (upstream).
